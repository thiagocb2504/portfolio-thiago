# Portfólio · Thiago Brito

Portfólio pessoal em HTML, CSS e JavaScript puro, publicado no GitHub Pages:
https://thiagocb2504.github.io/portfolio-thiago/

## Arquivos

- `index.html`: conteúdo da página (experiência, projetos, stack, formação e contato)
- `style.css`: tokens de cor e tipografia, layout responsivo e tema claro/escuro automático
- `script.js`: menu mobile, horário de Brasília, link ativo no menu, animações de entrada e botão de copiar e-mail
- `assets/CV_TI_THIAGO_BRITO.pdf`: currículo linkado nos botões da página

## Rodar localmente

```bash
python3 -m http.server 5500
```

Depois é só abrir `http://localhost:5500`.
