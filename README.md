# Portfólio — Thiago Brito

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro, com foco na apresentação de projetos de desenvolvimento Java/Backend.

## Publicação no GitHub Pages

Substitua os arquivos do repositório `portfolio-thiago` por estes arquivos e mantenha o GitHub Pages apontado para a branch `main` e pasta `/root`.

## Arquivos
- `index.html`: estrutura da página
- `style.css`: layout responsivo e visual
- `script.js`: menu mobile, header e animações de entrada
- `assets/curriculo-thiago-brito.pdf`: currículo disponibilizado no botão da página
