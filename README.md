# Portfólio · Thiago Brito

Portfólio pessoal em HTML, CSS e JavaScript puro, publicado no GitHub Pages:
https://thiagocb2504.github.io/portfolio-thiago/

## Arquivos

- `index.html`: conteúdo da página (experiência, projetos, stack, formação e contato)
- `style.css`: tokens de cor e tipografia, layout responsivo e tema escuro
- `script.js`: menu mobile, horário de Brasília, link ativo no menu, animações de entrada, títulos em neon, botão de copiar e-mail e detalhes dos projetos
- `electric-logo.js`: versão em JavaScript puro do componente ElectricLogo do React Bits (usa a biblioteca `ogl` via CDN)
- `electric-hero.js`: desenha o nome com a fonte do título e aplica o efeito elétrico no topo da página
- `gooey-nav.js`: versão em JavaScript puro do componente GooeyNav do React Bits
- `nav-header.js`: monta a navegação gooey no header (só no desktop) e move a bolinha conforme a rolagem
- `particles.js`: versão em JavaScript puro do componente Particles do React Bits
- `particles-bg.js`: coloca as partículas vermelhas como fundo fixo da página
- `electric-border.js`: versão em JavaScript puro do componente ElectricBorder do React Bits
- `electric-borders.js`: liga a borda elétrica nos cards e no bloco de IA quando eles chegam perto da tela
- `assets/CV_TI_THIAGO_BRITO.pdf`: currículo linkado nos botões da página
- `assets/projetos/`: capturas de tela dos projetos web (Vini Vinhos e Sistema de Pagamentos)

## Rodar localmente

```bash
python3 -m http.server 5500
```

Depois é só abrir `http://localhost:5500`.
